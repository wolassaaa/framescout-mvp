# FrameScout 云端 AI 校准

这份流程用于先用少量代理图验证云端视觉模型。FrameScout 不上传 RAW、原始照片路径或映射母版；云端请求只包含重新编码、受像素和字节限制的 JPEG 代理图。

## 1. 在服务终端设置密钥

关闭当前 FrameScout 服务终端，新开 PowerShell，在同一个窗口执行：

```powershell
Set-Location "C:\Users\woola\Downloads\framescout-mvp"
$env:DASHSCOPE_API_KEY = "你的百炼 API Key"
.\target\release\framescout-local-service.exe
```

密钥只存在于服务进程环境中。不要把密钥输入浏览器、写进项目文件或截图。

## 2. 选择 20 张预算校准

在网页顶部打开“AI 通道”：

1. 选择“千问视觉”。
2. 运行方式选择“云端识别”。
3. 项目云端预算上限设为 `20` 分，并发设为 `2`。
4. 保存运行设置，然后开始 AI 分析。

当前千问配置按每张代理图 1 分做保守估算。预算按“项目 + 供应商 + 模型”累计，达到估算上限后服务会硬停止；供应商实际账单仍以其用量记录为准。

## 3. 故障和恢复规则

- 每张代理图在发出网络请求前写入本地计费账本。
- 429、503 等明确的临时 HTTP 状态最多重试三次。
- 网络超时可能已经到达供应商，因此不会自动二次发送；该照片进入“需要复核”。
- 解析失败或模型证据不足同样进入“需要复核”，不会保留旧的“淘汰”结论。
- 同一项目、供应商和模型已经完成的照片不会因重复点击再次付费。更换模型会建立新的预算维度。

## 4. 检查结果

重点检查：

- 人像：眼睛、表情、面部和主体清晰度是否合理。
- 动作：有意追焦或运动模糊是否被保护。
- 场景：人物、车辆、空镜和环境叙事标签是否准确。
- Top-N：最终数量由本地确定性排序完成；构图证据和连拍多样性会参与排序，不会再上传第二轮联系表。
- 错误：失败原因应直接显示在网页，并在服务终端保留详细日志。

## 5. 清除密钥

停止服务终端后，该进程中的密钥随之失效。也可以执行：

```powershell
Remove-Item Env:DASHSCOPE_API_KEY
```

重新启动服务时若没有密钥，千问通道会显示不可用，本机分析仍可继续使用。
