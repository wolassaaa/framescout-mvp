# FrameScout Review 包

这是给交付前人工 review 的浏览器版本。解压后运行根目录的 `START-REVIEW.ps1`，脚本会启动可见的本地服务终端和本机网页，然后打开系统浏览器。

## Review 入口

在 PowerShell 中运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\START-REVIEW.ps1
```

浏览器地址是 `http://127.0.0.1:5173/`。本地服务使用 `http://127.0.0.1:4310/`，终端会显示导入和 AI 的真实进度。

## 建议检查

1. 导入一小组 JPG，确认首批缩略图能在完整扫描前出现。
2. 在审阅台和网格中分别使用全选、清除选择、筛选和 `Ctrl+A`，确认选择数量保持一致。
3. 打开 AI 通道，确认本地服务状态、分析进度和失败提示都是真实状态。
4. 在标签页检查 AI 阶段、人工阶段和自定义标签是否都能筛选资产。
5. 在导出页检查目标目录、RAW 映射、文件夹结构和标签规则；确认源目录未被写入。
6. 将浏览器缩放设为 80%、100%、125% 和 150%，确认导航、主图、检查器和底部胶片条不重叠。

## 包内边界

- 不包含任何源照片。
- 不包含 `node_modules`、Python 虚拟环境、Rust 开发构建缓存、压力测试缓存或数据库缓存。
- 不包含当前仍处于 `development-only-pending-review` 的模型权重；模型授权完成后应单独安装到 `%LOCALAPPDATA%\FrameScout\models`。
- 云端 API 密钥不会写入包，也不会写入项目数据库；需要时只在启动服务的终端环境中配置。

所有导入、缩略图、分析结果和导出预览都应写入 FrameScout 缓存或用户指定的导出目录，源照片保持只读。
